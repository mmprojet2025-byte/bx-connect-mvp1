# Politique de sécurité

## Versions prises en charge

Bx-Connect est actuellement un MVP en préparation de préproduction. Aucune version publique de production n'est annoncée comme prise en charge.

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique pour une vulnérabilité, un secret exposé ou une donnée personnelle.

Utilisez exclusivement la fonction privée **Report a vulnerability** des GitHub Security Advisories de ce dépôt. Si cette fonction n'est pas disponible, ne publiez aucune information sensible dans une issue publique et attendez qu'un canal privé soit activé.

Le signalement devrait indiquer, sans inclure de secret réel :

- la zone affectée (`backend`, `frontend-web` ou `mobile`) ;
- les étapes minimales de reproduction ;
- l'impact estimé ;
- une proposition de correction, si disponible.

## Informations interdites dans un signalement public

- mots de passe, jetons, clés API ou secrets JWT ;
- données bancaires ou identifiants financiers ;
- données personnelles d'utilisateurs ;
- fichiers d'environnement ou dumps de base de données ;
- captures d'écran non expurgées.

## Délai et traitement

Un accusé de réception et un délai de traitement seront définis avant l'ouverture publique du dépôt. Une vulnérabilité ne doit être divulguée publiquement qu'après correction et accord explicite du responsable du projet.
