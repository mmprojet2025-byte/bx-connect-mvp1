# Images locales

Ce dossier accueillera les images locales suivantes :

- `home.png` : image de l'accueil.
- `login.png` : image de l'écran de connexion.
- `signup.png` : image de l'écran d'inscription.
- `activity-default.png` : image par défaut d'une activité.
- `group-default.png` : image par défaut d'un groupe.
- `profile-default.png` : image de profil par défaut.

Ces images ne sont pas encore intégrées dans les écrans ou les composants.
